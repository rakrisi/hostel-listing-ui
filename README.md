# HostelHub - Mobile-First Hostel/PG Search UI

A next-generation, mobile-first Hostel/PG search UI built with pure HTML + TailwindCSS. This UI is designed to feel like a native mobile app with modern design, smooth micro-interactions, and fast usability.

## 📱 Features

### 1. Home Screen (Search Focused)
- Large hero search box with smart autocomplete
- Popular search chips
- Category browsing (Boys/Girls/Co-ed)
- Featured hostels horizontal scroll
- Clean header with logo and profile icon
- Thumb-reach optimized layout

### 2. Hostel Listing Screen
- Beautiful hostel cards with swipeable image carousel
- Gender tags (Boys/Girls/Co-ed)
- Rating stars and price display
- Amenities icons row (WiFi, AC, Food, Laundry, Power Backup)
- Contact Owner and View Details buttons
- Compact sticky top bar with search, filters, and sort
- Mobile-style bottom sheet filters
- Shimmer skeleton loaders

### 3. Hostel Detail Page
- Swipeable full image gallery
- Sticky bottom bar with Call/WhatsApp buttons
- Verified badge display
- Location with walking distance
- Room pricing options (Single/Double/Triple)
- Amenities grid with icons
- Food availability section
- Rules & policies
- Map preview
- Scrollable reviews

## 🎨 Design System

- **Primary Color**: `#4B70FF`
- **Rounded Corners**: `rounded-2xl`
- **Shadows**: `shadow-lg`
- **Transitions**: `transition-all duration-200`
- **Typography**: Inter font, clean and mobile-readable
- **Icons**: Lucide Icons
- **Glassmorphism**: For floating action buttons
- **Pull-to-refresh**: Hint animation

## 🚀 Getting Started

Simply open any of the HTML files in a modern web browser:

```bash
# Open home page
open index.html

# Or use a local server
npx serve .
```

## 🛠️ Technologies Used

All pages are fully responsive and optimized for:

- Tablets
